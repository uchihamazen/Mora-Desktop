# Mora icon

`mora-mark.png` is the shared Mora artwork: a blue folded-ribbon monogram on a
rounded navy tile. It is covered by the repository's [MIT License](../../LICENSE).
It does not use Meta's symbol or OpenAI's artwork.

`mora-mark.svg` embeds that PNG so existing sidebar, welcome, assistant-avatar
and favicon references use the same design without a runtime dependency.
`mora-mark.ico` contains PNG frames at 16, 24, 32, 48, 64, 128, and 256 px,
resampled from the PNG with Chromium for the window and Windows packaging icon.
Update all three assets together when changing the design.
